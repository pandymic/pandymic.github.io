Static sites

A static site is just files: HTML, CSS, JavaScript and assets. With no server-side code to run, hosting is cheap, fast and hard to break. Build once, serve anywhere.

Build pipelines

  • Keep sources and generated output separate.
  • Make builds repeatable: pin versions and lock dependencies.
  • Automate the boring parts: compile, minify, deploy.
